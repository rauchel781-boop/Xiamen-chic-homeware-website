# SEO Operations

Last updated: 2026-10-14

## Current Site

- Framework: Next.js 14 App Router
- Domain: `https://xmchichomeware.com`
- Business: wooden homeware and kitchenware manufacturer for overseas buyers
- Main data source: `wp-data/*.json`
- Main content routes:
  - Products and product categories: `app/[locale]/products/[slug]/page.js`
  - Blog posts: `app/[locale]/blog/[slug]/page.js`
  - Industry briefs: `app/[locale]/briefs/[slug]/page.js`
  - Hand-coded SEO landing pages: `app/[locale]/*/page.js`
- Locales: `en`, `es`, `de`, `fr`, `ja`

## What Is Already In Place

- `robots.txt` generated by `app/robots.js`
- `sitemap.xml` generated by `app/sitemap.js`
- Canonical and hreflang helpers in `i18n/routing.js`
- Global Organization / Manufacturer / LocalBusiness schema in `app/[locale]/layout.js`

- BlogPosting schema on blog pages

- Legacy WordPress and WooCommerce URLs redirected in `next.config.js`

### Release Verification

```bash
npm run build
npm run seo:audit
npm run seo:verify-build
npm run seo:verify-live
```

The verification script checks canonical URLs, document languages, homepage titles, reciprocal sitemap entries, new article paragraphs, and selected paragraphs from the previous release. `--build` reads actual production output; live mode reads the public website and returns a nonzero exit code if the release markers are absent. Optional usage:

```bash
node scripts/verify-seo-deployment.mjs https://xmchichomeware.com --report live-check.json
```

Coolify's application must use the intended repository and `main` branch. Confirm a successful deployment for the pushed commit, then run the live check. Do not interpret an empty GitHub deployment/check list as a successful or failed Coolify deployment.

The curated content update is repeatable without adding duplicate paragraphs:

```bash
node scripts/add-contextual-product-links.mjs
node scripts/add-contextual-product-links.mjs --apply
```

## Metadata Rules

- Title target: 50-60 characters.
- Meta description target: 150-160 characters.
- Every product, category, blog, and useful page needs unique metadata.
- Avoid AI-style words: `delve`, `game-changer`, `testament`, `revolutionary`, `unparalleled`.
- Do not invent certifications, exact dimensions, stock status, or compliance claims.
- Image alt text should describe the visible product and material without keyword stuffing.

## Operating Rules

- Before code changes, check `git status --short --branch`.
- Do not overwrite existing user changes.
- Keep outputs, audits, and generated drafts in existing project folders.
- For SEO content, update source data in `wp-data/*.json` or the matching page file, not compiled `.next` output.
- After meaningful SEO changes, run:

```bash
npm run seo:audit
npm run build
```

If `npm run build` fails, fix the build before considering the SEO task complete.
